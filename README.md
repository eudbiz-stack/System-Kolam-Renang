# System-Kolam-Renang
Sistem informasi kolam renang berbasis web dengan fitur pengelolaan tiket, pemesanan, verifikasi pembayaran, manajemen pengguna, dan dashboard admin.

**Sistem Informasi Kolam Renang**

Aplikasi berbasis web untuk mengelola operasional kolam renang, mulai dari pengelolaan tiket, pemesanan, hingga verifikasi pembayaran. Dilengkapi panel administrator untuk memudahkan pengelolaan pengguna, pengaturan sistem, dan pemantauan aktivitas pemesanan.

**Fitur Utama:**
- Dashboard Admin
- Kelola Tiket
- Manajemen Pengguna
- Kelola Pemesanan
- Verifikasi Pembayaran
- Pengaturan Sistem
- Halaman Beranda
- Login dan Logout

**Teknologi:** PHP, MySQL, HTML, CSS, dan JavaScript.
